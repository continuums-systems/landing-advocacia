# Advocacia Silva & Associados - Landing Page

Landing page premium para escritório de advocacia, desenvolvida com React, TypeScript, Tailwind CSS e Framer Motion.

## Stack

- React 19
- Vite
- TypeScript
- Tailwind CSS v4
- Framer Motion
- React Icons
- React Helmet Async

## Executar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
